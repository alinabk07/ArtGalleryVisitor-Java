# Art Gallery Visitor Management System

## Project Overview
This project is a Java-based Art Gallery Visitor Management System developed using object-oriented programming principles. It allows the management of visitor information through a simple desktop application.

## Features
- Visitor Registration
- Standard and Elite Visitor Management
- Duplicate Visitor ID Validation
- Graphical User Interface (GUI)
- Object-Oriented Design

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- BlueJ

## Project Files
- Java source code (.java)
- BlueJ project files
- Project documentation (PDF)
